# fivem-queue-status

Displays a live player queue status UI for FiveM servers using native events.

## Stack

Primary language: **Lua**

## Project structure

- `fxmanifest.lua` — Server-side queue tracking and client-side UI display
- `server.lua` — server logic
- `client.lua` — client UI

## Usage

Review the source files and install any dependencies referenced by the project before running it.
